INC000099290453 (P2) - RunFeed is getting locked

Date: 08/05/2026

Requester: RunFeed is getting locked

 

Description:

 

Run feed estava lockado e parado (imagem em baixo sintoma)

 

![talenduser@pt 402adr: /var/SP/data1/dmaap/ runFeed \$ . /runFeed. sh

Actions Taken:

Remover o runFeed.lck na 402 - /var/SP/data1/dmaap/runFeed

 

Este ficheiro runFeed.lck loca todo o processo (escolhe qual job do
talend vai ser executado) só após este lock é que o talend começa a
executar, logo quando esta locado é global e todas as feeds ficam a
espera de ser libertado.

 

Resolution:

 

Eliminar este ficherio .lck resolveu a situação (suspeita do
Dmaap_Main_06 estar rebentado e por consequancia a lockar todos os
outros)

 

 

NOTAS:

 

No script runFeed.sh foi mudado na linha 449+- (query com o cte com o
nome ready) verifica quais os jobs de dmaap que estão ready to run e
disponiveis para serem escolhidos. Fizemos alteração neste script para
que de momento o dmaap_06 seja excluido de ser escolhido.

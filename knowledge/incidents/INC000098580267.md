search do GCP BigQuery para localizar a SP que alimenta esta tabela
(\"oppt 061\"), que seria:

\- Buscar a query principal que é usada para insert na tabela do report.

\- Executar a query abaixo para confirmar se o user utilizou o filtro
mencionado e qual o status do report (se DONE, ERROR ou PREPARING DATA,
que justificaria o Anvil não ter chamado a SP).

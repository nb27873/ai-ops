Initial Diagnosis:

\- DAG bde_bau_da_cops_trigger_retention create_success_files is skipped

 

 

Actions Taken:

 

 

Problemas detetados:

1.  A task create success file não estava a correr, estava a ser
    skipped. Impacto: Os dados não seguem para D&A.

    a.  Explicação: A DAG processa ao dia e faltando um ficheiro a ser
        processado nesse dia o dia não fica fechado, logo a task do
        create succes file é skipped.

> O processamento da DAG é sequencial, entrando outros dias ele
> processa, mas só envia os dados para D&A quando todos os ficheiros
> estão processados de forma sequencial.
>
> Resolução: Processar o ficheiro em falta e ir validando a tabela
> vf-pt-datahub-prd-mgmt.vfpt_dh_mgmt_dmaap_metadata_s.bde_ctrl_bau_da_cops
> se os dias vão ficando fechados
